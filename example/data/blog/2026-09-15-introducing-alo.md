ছোট একটা ওয়েবসাইট বানাতে গিয়ে আমরা বারবার একই জায়গায় আটকাই। হেডার আর ফুটার প্রতিটা পেইজে কপি করতে হয়, ব্লগের নতুন লেখা যোগ করতে HTML ঘাঁটতে হয়। আবার বড় টুল নিলে শিখতে হয় নতুন ভাষা, কনফিগ ফাইল আর শখানেক প্যাকেজ।

**আলো** এই দুইয়ের মাঝখানের জায়গাটা ধরতে চায়।

## যা আলাদা

- তুমি লেখো সাধারণ HTML, CSS আর JavaScript।
- হেডার বা কার্ডের মতো জিনিস একবার লিখে `<Header />` দিয়ে সব জায়গায় বসাও।
- ব্লগের লেখা রাখো Markdown ফাইলে; প্রতিটা ফাইল থেকে নিজে থেকেই পেইজ তৈরি হয়।
- বিল্ড করলে পাও সাধারণ স্ট্যাটিক ফাইল, যা যেকোনো হোস্টিংয়ে চলে।

## পাঁচ মিনিটে শুরু

```bash
npx @msilabs/alo init my-site
cd my-site
npm install
node alo dev
```

ব্রাউজারে `http://localhost:3000` খুললেই সাইট দেখা যাবে। কোনো ফাইল বদলে সেভ করলে পেইজ নিজে থেকে রিলোড হবে।
