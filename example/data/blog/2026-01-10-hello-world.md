Alo দিয়ে লেখা **প্রথম পোস্ট**। এই লেখাটা Markdown-এ, আর ফাইলের নামের তারিখটাই পোস্টের তারিখ।

## যা যা লাগে

- একটা টেক্সট এডিটর
- Node.js ২২ বা নতুন
- HTML, CSS আর JS-এর সাধারণ জ্ঞান

## একটা কম্পোনেন্ট

```html
<Card title="হ্যালো">
    <p>কার্ডের ভেতরের লেখা</p>
</Card>
```

| ফোল্ডার       | কাজ                 |
| :------------ | :------------------ |
| `pages/`      | রাউটিং              |
| `components/` | রিইউজেবল কম্পোনেন্ট |
| `data/`       | JSON আর Markdown    |

আরও জানতে দেখো [আমাদের কথা](/about/)।
