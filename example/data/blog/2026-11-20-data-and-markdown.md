মেনুর লিংক, প্রশ্নোত্তর বা ব্লগের লেখা HTML-এর ভেতরে লিখলে কিছু বদলাতে গেলেই টেমপ্লেট ঘাঁটতে হয়। আলোতে এগুলো থাকে `data/` ফোল্ডারে, আর সব পেইজ, লেআউট আর কম্পোনেন্টে পাওয়া যায় `data` নামে।

## একটা JSON ফাইল

`data/menu.json`:

```json
[
    { "href": "/", "label": "হোম" },
    { "href": "/blog/", "label": "ব্লগ" }
]
```

এটা পাওয়া যায় `data.menu`-তে। লুপ চালাও `<template for>` দিয়ে:

```html
<nav>
    <template for="link in data.menu">
        <a href="{{ link.href }}">{{ link.label }}</a>
    </template>
</nav>
```

ফাইলের নামে হাইফেন থাকলে নামটা camelCase হয়ে যায়: `data/footer-links.json` পাওয়া যায় `data.footerLinks`-এ।

## লেখায় ভর্তি ফোল্ডার

যে ফোল্ডারে শুধু ফাইল থাকে, সেটা হয় একটা অ্যারে। `data/blog/`-এর প্রতিটা `.md` বা `.json` ফাইল `data.blog`-এর একটা আইটেম। Markdown ফাইলের শুরুতে থাকে ছোট একটা ফ্রন্ট ম্যাটার:

```markdown
---
title: প্রথম লেখা
tags: [গাইড]
---

এখান থেকে লেখা শুরু।
```

ফাইলের নাম থেকে আসে আরও দুটো জিনিস। এই লেখার ফাইল `2026-11-20-data-and-markdown.md`, তাই এর `date` হলো `"2026-11-20"` আর `slug` হলো `"data-and-markdown"`। আইটেমগুলো সাজানো থাকে ফাইলের নাম অনুযায়ী, তাই পুরনো লেখা আগে আসে।

## প্রতিটা লেখার জন্য একটা পেইজ

`pages/blog/[slug]/page.alo` একটাই ফাইল, কিন্তু `data/blog/`-এর প্রতিটা আইটেমের জন্য একটা করে পেইজ বানায়। যেমন এই লেখার ঠিকানা `/blog/data-and-markdown/`। ভেতরে আইটেমটা পাওয়া যায় `item`-এ:

```html
<template>
    <article>
        <h1>{{ item.title }}</h1>
        {{{ item.body }}}
    </article>
</template>
```

`{{ }}` লেখা বসায় escape করে, আর `{{{ }}}` বসায় হুবহু HTML হিসেবে। Markdown থেকে তৈরি হওয়া `body` তাই বসে `{{{ }}}` দিয়ে।

## ডেটা শুধু পড়া যায়

`data` পেইজের ভেতর থেকে বদলানো যায় না। নতুন লেখা আগে দেখাতে `data.blog.reverse()` লিখলে এরর আসবে; লেখো `data.blog.toReversed()`, যা নতুন একটা অ্যারে দেয় আর আসল ডেটা যেমন ছিল তেমন রাখে।

## খসড়া

ফ্রন্ট ম্যাটারে `draft: true` দিলে লেখাটা শুধু `node alo dev`-এ দেখা যায়, `node alo build`-এর আউটপুটে আসে না। তাই অর্ধেক লেখা ভুল করে প্রকাশ হয়ে যায় না।
