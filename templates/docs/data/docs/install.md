এই পাঁচটি নমুনা পাতা Alo-র ছোট একটি গাইড। পড়া শেষে এগুলো মুছে নিজের ডকুমেন্টেশন লিখুন।

## নতুন প্রজেক্ট

Alo চালাতে Node.js 22 বা নতুন লাগে।

```bash
npx @msilabs/alo init my-docs --template docs
cd my-docs
npm install
node alo dev
```

এরপর ব্রাউজারে `http://localhost:3000` খুলুন। ফাইল বদলে সংরক্ষণ করলে পাতা নিজে থেকে রিলোড হয়।

## ফোল্ডারগুলো

```text
pages/        প্রতিটি page.alo একটি ঠিকানা
components/   বারবার ব্যবহার করার টুকরো
data/         JSON আর Markdown ফাইল
global/       সব পাতার CSS আর JS
public/       ছবির মতো ফাইল, যেমন আছে তেমন কপি হয়
```

## এই সাইটে নতুন পাতা

প্রতিটি পাতা `data/docs/`-এর একটি Markdown ফাইল। এই পাতাটি আছে `data/docs/install.md`-এ, তাই এর ঠিকানা `/docs/install/`।

নতুন পাতা যোগ করতে সেখানে একটি `.md` ফাইল রাখুন:

```md
---
title: পাতার নাম
summary: সূচিতে দেখানোর এক লাইন।
section: শুরু
order: 2
---

এখানে লেখা শুরু করুন।
```

- `section`: পাশের মেনুর কোন অংশে পাতাটি বসবে। অংশগুলোর নাম আর ক্রম আছে `data/sections.json`-এ; নামটি হুবহু মিলতে হবে।
- `order`: পুরো ডকসে পাতার ক্রম। ছোট সংখ্যা আগে আসে; "আগের" আর "পরের" লিংকও এখান থেকে ঠিক হয়।

সাইটের নাম `data/site.json`-এ, ওপরের মেনু `data/menu.json`-এ, আর রঙ ও ফন্ট `global/theme.css`-এ।
