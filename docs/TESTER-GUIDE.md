# বাইরের টেস্টারের গাইড

## টেস্টারের জন্য

ধন্যবাদ! Alo একটা নতুন স্ট্যাটিক সাইট ফ্রেমওয়ার্ক। আমরা জানতে চাই, HTML জানা কেউ আগে কিছু না দেখে কত সহজে কাজ শুরু করতে পারে। এখানে পরীক্ষা হচ্ছে Alo-র, তোমার নয়। কোথাও আটকালে সেটাই আমাদের সবচেয়ে কাজের তথ্য।

**যা লাগবে:** Node.js ২২ বা নতুন, একটা টেক্সট এডিটর, আর একটা ব্রাউজার।

**নিয়ম:**

- শুধু [README](../README.md)-র প্রথম অংশ পড়বে, "পরে দেখো"-এর আগ পর্যন্ত।
- অন্য কোনো ডকুমেন্ট, সোর্স কোড বা ইন্টারনেট ঘাঁটবে না।
- কাজ করতে করতে যা ভাবছ, মুখে বলো। পাশে একজন চুপচাপ লিখে রাখবে।
- মোট সময় ১০ মিনিট। শেষ না হলেও সমস্যা নেই।

**কাজগুলো:**

1. একটা নতুন প্রজেক্ট বানাও আর ব্রাউজারে খোলো।
2. একটা নতুন পেইজ যোগ করো: `/contact/` ঠিকানায়, একটা শিরোনাম আর একটা ই-মেইল লিংকসহ। মেনুতেও লিংকটা যোগ করো।
3. একটা নতুন কম্পোনেন্ট বানাও, যেমন `Notice`, যা `message` নামের একটা প্রপ নিয়ে সেটা হলুদ বাক্সে দেখায়। সেটা হোম পেইজে দুবার ব্যবহার করো, দুটো আলাদা লেখা দিয়ে।
4. ব্লগে একটা নতুন Markdown লেখা যোগ করো, আর সেটা ব্লগের তালিকায় আর নিজের পেইজে দেখা যাচ্ছে কিনা দেখো।

### যা বিশেষভাবে খেয়াল করবে

- `props.message` লিখতে পেরেছে নাকি সরাসরি `{{ message }}` লিখেছে; লিখলে এরর মেসেজ পড়ে নিজে ঠিক করতে পেরেছে কিনা।
- কম্পোনেন্টের ফাইলের নাম বড় হাতে দিয়েছে কিনা (`Notice.alo`)।
- মেনুর লিংক কোথায় যোগ করতে হবে (`data/menu.json`) সেটা নিজে খুঁজে পেয়েছে কিনা।
- Markdown ফাইলের নামে তারিখ আর ফ্রন্ট ম্যাটার ঠিকমতো লিখেছে কিনা, নাকি `node alo new post` ব্যবহার করেছে।
- কোনো এরর মেসেজ পড়ে বুঝতে না পারলে, মেসেজটা হুবহু লিখে রাখো।
