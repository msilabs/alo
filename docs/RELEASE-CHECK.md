# রিলিজ যাচাই: v0.1.0

যাচাইয়ের তারিখ: ৬ নভেম্বর ২০২৬। উদাহরণ সাইট নতুন করে লেখার পরে (Alo-র নিজের ওয়েবসাইট) ৫, ৬, ৭ আর ৯ নম্বর যাচাই আবার চালানো হয়েছে; নিচের সংখ্যাগুলো নতুন উদাহরণের। এখানে [স্পেকের](SPEC.md) অংশ ২৪-এর প্রতিটা মানদণ্ড একটা একটা করে মেলানো হয়েছে। প্রতিটার পাশে আছে কীভাবে যাচাই হলো। যেগুলো স্বয়ংক্রিয়ভাবে যাচাই করা যায়নি, সেগুলো আলাদা করে "হাতে যাচাই বাকি" লেখা।

## বিস্তারিত

**১. dependency আর কনফিগ।** `npm ls` দেখায় `(empty)`। `init` করা প্রজেক্টে থাকে শুধু `package.json`, `alo` ফাইল আর এডিটরের সেটিং; Alo-র কোনো কনফিগ ফাইল নেই।

**২. টেস্ট।** লোকালি (macOS, Node 24) `npm test`-এ ৩১৭টা টেস্টের সবগুলো পাস করে। GitHub Actions-এ Linux আর Windows-এ Node 22, 24 আর 26, আর macOS-এ Node 24, মোট ৭টা job; সর্বশেষ সব run সফল, Windows-এর dev সার্ভার টেস্টসহ। স্পেক macOS-এও তিনটা ভার্সন চেয়েছিল; macOS runner-এর দীর্ঘ সারির কারণে মালিকের সিদ্ধান্তে এটা কমানো হয়েছে ([DECISIONS.md](../DECISIONS.md) #২৬)।

**৩ আর ৪. উদাহরণের ফাইল।** `test/e2e.test.js` `example/`-এর সব `.alo` ফাইল পড়ে দেখে: `import`, লোকাল `<link rel="stylesheet">` আর লোকাল `<script src>` নেই (Google Fonts-এর লিংক বাইরের, তাই চলে; #৮৭), আর `for`/`if`/`else-if`/`else` শুধু `<template>`-এ আছে।

**৫. উদাহরণ সাইট।**
- `node alo build` এরর বা সতর্কবার্তা ছাড়া চলে। দশটা পেইজ তৈরি হয়, আর খসড়া পোস্ট `dist/`-এ থাকে না।
- আউটপুটটা একটা সাধারণ স্ট্যাটিক সার্ভারে চালিয়ে হোম থেকে প্রতিটা লিংক, ছবি, CSS আর JS খোলা হয়েছে, সবগুলো 200 দিয়েছে। এই সার্ভার ফোল্ডারের জন্য শুধু `index.html` দেয়, এর বেশি কিছু করে না।
- উদাহরণের আসল `components.js` একটা নকল DOM-এ চালিয়ে ক্লিক করে দেখা হয়েছে:
  - FAQ ক্লিকে খোলে আর বন্ধ হয়।
  - Counter ১০ থেকে শুরু হয়; দুবার `+` আর একবার `−` চাপলে ১১ হয়, বাংলা অঙ্কে।
  - মোবাইল মেনু খোলে, আর তিনটাতেই `aria-expanded` ঠিকঠাক বদলায়।
- headless Chrome-এ ডেস্কটপ আর ৩৯০px মোবাইল মাপে হোম, গাইড, "কেন আলো", ব্লগ পোস্ট আর 404-এর স্ক্রিনশট দেখা হয়েছে; মোবাইলে মেনু বোতাম দেখা যায়, আর লেখা পর্দার বাইরে যায় না।
- **হাতে যাচাই বাকি:** আসল ব্রাউজারে ক্লিক করে FAQ, Counter আর মোবাইল মেনু দেখা, আর ডার্ক মোড।

**৬. base path।** `--base /repo/` দিয়ে বিল্ড করে আউটপুট `/repo/`-এর নিচে চালানো হয়েছে, আর ক্রল করে খোলা ১৪টা URL সবগুলো 200 দিয়েছে: পেইজ, হ্যাশসহ CSS আর JS, favicon, sitemap আর robots। e2e টেস্টও প্রতিটা পেইজের প্রতিটা `/` লিংকে `/repo/` আছে কিনা দেখে। `route.path`-এ base নেই, তাই মেনুর active লিংক কাজ করে।

**৭. প্রোডাকশন আউটপুট।**
- `style.<hash>.css` এক লাইনে মিনিফাই করা।
- সব asset-এর নামে কনটেন্টের SHA-256 হ্যাশ।
- `sitemap.xml`-এ আটটা পাবলিক পেইজ, `https://msilabs.github.io/...` আকারে। `noindex` লাগানো launch পেইজ আর 404 বাদ।

**৮. রানটাইম।** তৈরি হওয়া কোনো JS-এ `Proxy`, `MutationObserver` বা রিঅ্যাক্টিভ কিছু নেই; e2e টেস্ট এটা দেখে। launch আর 404 পেইজে শুধু `global.js` যায়, `components.js` বা পেইজ JS যায় না।

**৯. লাইভ রিলোড।** dev সার্ভার চালিয়ে চার ধরনের ফাইল বদলানো হয়েছে, আর সেভ থেকে রিলোড ইভেন্ট পর্যন্ত সময় মাপা হয়েছে:

| ফাইল                                                 | সময়   |
| ---------------------------------------------------- | ------ |
| `.alo` (`components/Card.alo`)                       | ১২৮ms  |
| JSON (`data/menu.json`)                              | ১৩২ms  |
| Markdown (`data/blog/…-components-and-layouts.md`)   | ১২৭ms  |
| CSS (`global/theme.css`)                             | ১২৬ms  |

এর মধ্যে ১০০ms হলো ইচ্ছাকৃত debounce।

**১০. এরর মেসেজ।** প্রতিটা ভুল আলাদা ছোট প্রজেক্টে আসল CLI দিয়ে চালানো হয়েছে:

| ভুল                    | ফল                                                                 |
| ---------------------- | ------------------------------------------------------------------ |
| ভুল কম্পোনেন্ট নাম     | এরর, ফাইল:লাইন, কাছাকাছি নামের পরামর্শ                             |
| ভুল প্রপ নাম           | সতর্কবার্তা `pages/page.alo:2:9`, "তুমি কি `title` বোঝাতে চেয়েছিলে?" |
| ভাঙা JSON              | এরর `data/team.json:3:2`                                           |
| অসাপোর্টেড YAML        | এরর `data/post.md:4:1`, `.json`-এর ইঙ্গিত                          |
| বন্ধ না করা ট্যাগ      | এরর `pages/page.alo:3:5`                                           |
| ডেটা বদলানোর চেষ্টা    | এরর `pages/page.alo:2:3`, `toReversed()`-এর ইঙ্গিত                  |
| `<li if>`              | সতর্কবার্তা `pages/page.alo:2:7`                                   |
| কম্পোনেন্টে লজিক       | এরর `pages/page.alo:2:3`, `<template for>` দিয়ে মোড়ানোর ইঙ্গিত     |

এই যাচাইয়ের সময় একটা বাগ ধরা পড়েছিল। এক আইটেমের অ্যারেতে `data.blog.reverse()` লিখলে এরর আসত না, কারণ উল্টানোর মতো কিছু ছিল না বলে frozen অ্যারে কিছু লেখার চেষ্টাই করত না। এখন ডেটার প্রতিটা অ্যারেতে `reverse`, `sort`, `push` আর এ ধরনের মেথড সবসময় এরর দেয় (#৮৩)। regression টেস্টও যোগ হয়েছে।

**১১. নতুন ইউজারের পথ।** প্যাকেজটা এখনো npm-এ নেই, তাই `npm pack` দিয়ে আসল প্যাকেজ ফাইল বানিয়ে পুরো পথটা চালানো হয়েছে:
- সেই ফাইল দিয়ে `alo init my-site` চলেছে।
- তারপর `npm install` হয়েছে: ১টা প্যাকেজ, কোনো dependency নেই।
- `node alo build` চলেছে।
- `node alo dev` চালু হয়েছে, পেইজ 200 দিয়েছে, আর Markdown পোস্টও এসেছে।

প্যাকেজে ৪১টা ফাইল, ৫৬KB; টেস্ট বা `example/` যায় না। npm-এ প্রকাশের পরে আসল `npx @msilabs/alo init my-site` দিয়ে একবার আবার দেখে নেওয়া ভালো।

**১২. বাইরের টেস্টার।** এটা মানুষের কাজ। চেকলিস্ট আর পর্যবেক্ষণ লেখার টেমপ্লেট আছে [TESTER-GUIDE.md](TESTER-GUIDE.md)-এ।

**১৩. Alpine.js।** e2e টেস্টের ছোট প্রজেক্টে `x-data="{ open: false }" @click="open = !open" :aria-expanded="open"` আউটপুটে হুবহু থাকে।

## প্রকাশের আগে মালিকের কাজ

1. আসল ব্রাউজারে `example/` দেখে নেওয়া: `cd example && node ../bin/alo.js dev`। দেখার জিনিস:
   - FAQ, Counter আর মোবাইল মেনু।
   - কোনো ফাইল বদলালে রিলোড হয় কিনা।
   - ভুল লিখলে এরর overlay আসে কিনা।
2. বাইরের একজন টেস্টারকে দিয়ে [TESTER-GUIDE.md](TESTER-GUIDE.md) অনুযায়ী পরীক্ষা করানো, আর যেখানে আটকেছে সেখানে README বা এরর মেসেজ ঠিক করা।
3. `npm publish --access public`।
