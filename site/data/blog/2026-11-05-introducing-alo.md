ছোট একটি ওয়েবসাইট বানাতে গিয়ে আমরা বারবার একই জায়গায় আটকাই। হেডার আর ফুটার প্রতিটি পেইজে কপি করতে হয়, ব্লগের নতুন লেখা যোগ করতে HTML খুলে বদলাতে হয়। আবার বড় টুল নিলে শিখতে হয় নতুন ভাষা, কনফিগারেশন ফাইল আর প্রায় একশোটি প্যাকেজ।

**আলো** এই দুইয়ের মাঝখানের জায়গাটি ধরতে চায়।

## যা আলাদা

- লিখুন সাধারণ HTML, CSS আর JavaScript।
- হেডার বা কার্ডের মতো অংশ একবার লিখে `<Header />` দিয়ে সব জায়গায় বসান।
- ব্লগের লেখা রাখুন Markdown ফাইলে; প্রতিটি ফাইল থেকে নিজে থেকেই পেইজ তৈরি হয়।
- বিল্ড করলে পান সাধারণ স্ট্যাটিক ফাইল, যা যেকোনো হোস্টিংয়ে চলে।

## পাঁচ মিনিটে শুরু

```bash
npx @msilabs/alo init my-site
cd my-site
npm install
node alo dev
```

ব্রাউজারে `http://localhost:3000` খুললেই সাইট দেখা যাবে। কোনো ফাইল বদলে সংরক্ষণ করলে পেইজ নিজে থেকে রিলোড হবে।
