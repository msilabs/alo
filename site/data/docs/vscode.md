## এটি কী করে

**Alo** এক্সটেনশন পাওয়া যায় [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=msilabs.alo-vscode)-এ, বিনামূল্যে। এটি Alo-র নিজের কোড দিয়েই প্রজেক্ট পড়ে। তাই এডিটর আর `node alo build` একই নিয়ম মানে: একই কম্পোনেন্টের নাম, একই এরর, একই ইঙ্গিত।

## ইনস্টল

তিনটির যেকোনো একভাবে:

- VS Code-এ Extensions প্যানেল খুলুন (Cmd/Ctrl+Shift+X), খুঁজুন **Alo**, আর msilabs-এর এক্সটেনশনটি Install করুন।
- [Marketplace-এর পেইজ](https://marketplace.visualstudio.com/items?itemName=msilabs.alo-vscode) থেকে Install চাপুন।
- টার্মিনালে চালান:

```bash
code --install-extension msilabs.alo-vscode
```

ইনস্টলের পর `.alo` ফাইল আছে এমন যেকোনো ফোল্ডার খুললেই এক্সটেনশন চালু হয়। কোনো সেটিং লাগে না।

### নতুন প্রজেক্টে

Alo 1.1.0 থেকে `alo init` প্রজেক্টে একটি `.vscode/extensions.json` রাখে। ফোল্ডারটি VS Code-এ খুললে VS Code নিজেই এক্সটেনশনটি ইনস্টল করার প্রস্তাব দেয়।

```bash
npx @msilabs/alo init my-site
code my-site
```

### পুরনো প্রজেক্টে

আগের `alo init` দিয়ে বানানো প্রজেক্টের `.vscode/settings.json`-এ আছে `"*.alo": "html"`। এটি থাকলে VS Code `.alo` ফাইল HTML হিসেবেই খোলে, আর এক্সটেনশন কাজ করতে পারে না। এক্সটেনশন নিজেই এটি খুঁজে পায় আর সরানোর প্রস্তাব দেয়। চাইলে Command Palette (Cmd/Ctrl+Shift+P) থেকে নিজেও চালাতে পারেন **Alo: Open .alo Files as Alo**।

## রং

`{{ }}`, `{{{ }}}` আর `<template for / if / else>`-এর লজিক রঙিন হয় JavaScript-এর মতো, আর কম্পোনেন্ট ট্যাগ আলাদা রঙে। `<style>` আর `<script>`-এর ভেতরে CSS আর JS পায় নিজেদের রং, কমেন্ট আর সাজেশন।

## কম্পোনেন্টের সাজেশন

- `<` লিখলেই আসে আপনার সব কম্পোনেন্টের তালিকা, ফোল্ডারেরগুলোসহ: `<Blog.PostCard>`।
- `<Card ` লিখে স্পেস দিলে আসে `Card` যে প্রপগুলো পড়ে, সেগুলো।
- কম্পোনেন্টের নামে Cmd/Ctrl+Click করলে তার ফাইল খোলে। মাউস রাখলে দেখায় তার প্রপগুলো।

## ডেটার সাজেশন

`{{ }}` আর `<template for="...">`-এর ভেতরে:

- `data.` লিখলে আসে `data/` ফোল্ডারের ফাইল আর তাদের key, মানসহ।
- `[slug]` পেইজে `item.` লিখলে আসে পোস্টের ফিল্ড।
- লুপ ভেরিয়েবলেও আসে তালিকার আইটেমের ফিল্ড, যেমন `for="post in data.blog"`-এর ভেতরে `post.`।
- কম্পোনেন্টে `props.` লিখলে আসে তার প্রপগুলো।
- `data.site.name`-এ Cmd/Ctrl+Click করলে খোলে `data/site.json`, ঠিক `"name"`-এর লাইনে।

## এরর আর সমাধান

সংরক্ষণের আগেই Alo প্রজেক্ট যাচাই করে, আর এরর ও সতর্কবার্তা দেখায় ঠিক সেই জায়গায়, ইঙ্গিতসহ। কম্পোনেন্টের ভেতরের এরর জানিয়ে দেয় কোন পেইজ সেটি ব্যবহার করেছে।

দাগের ওপর Cmd/Ctrl+. চাপলে Alo-র ইঙ্গিত অনুযায়ী সমাধান আসে:

- `<Crad>` বদলে `<Card>`, খোলা আর বন্ধের দুই ট্যাগেই।
- না-থাকা কম্পোনেন্টের ফাইল বানিয়ে খোলা।
- `<li if>`-কে `<template if>` দিয়ে মোড়ানো।
- ডেটা বদলে দেওয়া `sort()`-এর বদলে `toSorted()`।

## পেইজ আর লেআউট

প্রতিটি পেইজের ওপরে থাকে তার URL আর ব্রাউজারে খোলার বোতাম। লেআউটের ওপরে লেখা থাকে সেটি কয়টি পেইজকে মোড়ায়। ট্যাবে সারি সারি `page.alo`-এর বদলে দেখায় `about (page)`।

## কমান্ড

Command Palette-এ `Alo` লিখুন:

| কমান্ড | কাজ |
| --- | --- |
| **Alo: New…** | নতুন পেইজ, লেআউট, কম্পোনেন্ট বা পোস্ট বানায়, `alo new`-এর মতো |
| **Alo: Start Dev Server** | টার্মিনালে `alo dev` চালায়, আর স্ট্যাটাস বারে দেখায় ঠিকানা |
| **Alo: Build** | `dist/`-এ পুরো সাইট বানায় |
| **Alo: Open .alo Files as Alo** | পুরনো প্রজেক্টের `"*.alo": "html"` সেটিং সরায় |

## কোন Alo ব্যবহার করে

প্রজেক্টে `node_modules/@msilabs/alo` থাকলে এক্সটেনশন সেটিই ব্যবহার করে, তাই এডিটর আর আপনার বিল্ড সবসময় একমত। না থাকলে ব্যবহার করে এক্সটেনশনের সাথে আসা কপি।

## অচেনা ফোল্ডারে

যে ফোল্ডারকে VS Code-এ trust করেননি (Restricted Mode), সেখানে এক্সটেনশন এরর যাচাই করে না, আর dev server বা বিল্ড চালায় না, কারণ এগুলো আপনার টেমপ্লেটের কোড চালায়। রং, সাজেশন আর নতুন ফাইল বানানো তখনও চলে। ফোল্ডারটি trust করলে সব চালু হয়।

## সীমাবদ্ধতা

- Alo প্রথম এররেই থামে, তাই একবারে একটি এরর দেখায়। সতর্কবার্তা দেখায় সবগুলোই।
- `.alo` ফাইলে Format Document এখনো নেই।
- github.dev-এর মতো ভার্চুয়াল ওয়ার্কস্পেসে চলে না; ফোল্ডারটি কম্পিউটারে থাকতে হয়।
