## একটি Markdown ফাইল

Markdown ফাইল থাকে `data/` ফোল্ডারে। শুরুতে থাকতে পারে ছোট YAML ফ্রন্ট ম্যাটার:

```markdown
---
title: হ্যালো ওয়ার্ল্ড
tags: [intro, news]
draft: false
---

# প্রথম লেখা

এটি **Markdown**-এ লেখা।
```

এই ফাইল থেকে পাওয়া যায় `{ title, tags, draft, body }`। `body` হলো রেন্ডার করা HTML; বসাতে লিখুন:

```html
<article>
    <h1>{{ item.title }}</h1>
    {{{ item.body }}}
</article>
```

নতুন পোস্ট বানাতে:

```bash
node alo new post blog/hello-world    # data/blog/<আজকের তারিখ>-hello-world.md (খসড়া)
```

## ফ্রন্ট ম্যাটার

ফ্রন্ট ম্যাটার ঐচ্ছিক। থাকলে ফাইলের একেবারে প্রথম লাইন হবে `---`, আর শেষ হবে পরের `---` লাইনে। এতে চলে:

- `key: value`
- লেখা (কোট ছাড়া, বা `'সিঙ্গেল'` / `"ডাবল"` কোটে), সংখ্যা, `true` / `false` / `null`
- লিস্ট: `[a, b, "c d"]`, অথবা প্রতি লাইনে `- মান`
- `#` দিয়ে কমেন্ট

তারিখের মতো মান স্ট্রিংই থাকে। নেস্টেড অবজেক্টের মতো জটিল ডেটার জন্য `.json` ফাইল ব্যবহার করুন।

## যা যা লেখা যায়

| ধরন | সমর্থন |
| --- | --- |
| ব্লক | হেডিং, প্যারাগ্রাফ, উদ্ধৃতি, ক্রমযুক্ত আর ক্রমহীন লিস্ট (ভেতরে লিস্টসহ), কোড ব্লক, টেবিল, বিভাজক রেখা |
| ইনলাইন | `*জোর*`, `**গাঢ়**`, `~~কাটা লেখা~~`, `` `কোড` ``, লিংক, ছবি |
| নেই | footnote, task list, ইমোজি শর্টকোড, math |

### হেডিংয়ের `id`

প্রতিটি হেডিং নিজে থেকে `id` পায়, বাংলাতেও: `## যা যা লাগে` থেকে `id="যা-যা-লাগে"`। তাই `#যা-যা-লাগে` দিয়ে সরাসরি সেই অংশে লিংক করা যায়। একই হেডিং দুবার থাকলে দ্বিতীয়টি পায় `-2`।

### কোড ব্লক

ভাষার নাম দিলে সেটি বসে class-এ: `<pre><code class="language-js">`। Alo নিজে রং দেয় না; চাইলে পছন্দের হাইলাইটার যোগ করুন।

### লিংক আর ছবি

`/` দিয়ে শুরু হওয়া লিংক আর ছবিতে base path নিজে থেকে বসে, `.alo` ফাইলের মতোই:

```markdown
[আমাদের কথা](/about/)
![লোগো](/images/logo.svg)
```

## যা মনে রাখবেন

- Markdown-এর ভেতরে `{{ }}` প্রসেস হয় না; কনটেন্ট মানে শুধু ডেটা।
- Markdown-এর ভেতরের HTML হুবহু আউটপুটে যায়, স্যানিটাইজ করা হয় না। এটি আপনার নিজের লেখা ধরে নেওয়া হয়, তাই বাইরের কারও লেখা সরাসরি এখানে রাখবেন না।

## Markdown-এর স্টাইল

`{{{ item.body }}}` দিয়ে বসানো HTML-এ ফাইলের স্কোপড CSS লাগে না। স্টাইল দিতে ব্যবহার করুন `<style global>`, অথবা `global/` ফোল্ডারের CSS:

```html
<template>
    <div class="prose">
        {{{ item.body }}}
    </div>
</template>

<style global>
    .prose h2 {
        margin-top: 2.5rem;
    }
</style>
```
