## স্কোপড CSS

`.alo` ফাইলের `<style>`-এর CSS শুধু সেই ফাইলের এলিমেন্টে প্রযোজ্য হয়, তাই নাম মিলে যাওয়ার ভয় নেই:

```html
<!-- components/Card.alo -->
<template>
    <article class="card">
        <h3>{{ props.title }}</h3>
    </article>
</template>

<style>
    h3 {
        color: tomato;
    }
</style>
```

এখানে `h3`-এর রং বদলায় শুধু `Card`-এর ভেতরের `h3`-তে; সাইটের অন্য কোনো `h3` বদলায় না। পেইজ, লেআউট আর কম্পোনেন্ট, তিনটিতেই একই নিয়ম।

### কীভাবে কাজ করে

Alo ফাইলের প্রতিটি এলিমেন্টে একটি অ্যাট্রিবিউট বসায়, আর সিলেক্টরের শেষে সেটি যোগ করে:

```css
/* আপনি লেখেন */
.card h3 { color: tomato; }

/* আউটপুটে যায় */
.card h3[data-a-a1b2c3] { color: tomato; }
```

`@media`, `@supports`, `@container` আর `@layer`-এর ভেতরের নিয়মগুলোতেও এটি ঘটে। `@keyframes` আর `@font-face` অপরিবর্তিত থাকে।

## গ্লোবাল CSS

`global/` ফোল্ডারের সব `.css` ফাইল প্রযোজ্য হয় সব পেইজে। `<link>` দিয়ে যোগ করতে হয় না।

```
global/
├── base/
│   └── 01-reset.css
└── theme.css
```

ফাইলগুলো জোড়া হয় পুরো পাথের বর্ণানুক্রমে, সাবফোল্ডারসহ। তাই ক্রম ঠিক করতে নামের শুরুতে সংখ্যা দিন। রং, ফন্ট আর সাধারণ ক্লাস রাখার জায়গা এটিই।

## `<style global>`

`<style global>`-এর CSS স্কোপ ছাড়া হুবহু যায়। একটি ফাইলে `<style>` আর `<style global>` দুটিই থাকতে পারে:

```html
<style>
    .post h1 {
        font-size: 2rem;
    }
</style>

<style global>
    .post .body h2 {
        margin-top: 2.5rem;
    }
</style>
```

এটি লাগে দুই জায়গায়: `{{{ }}}` দিয়ে বসানো Markdown-এর কনটেন্টে, আর চাইল্ড কম্পোনেন্টের স্টাইলে।

## চাইল্ড কম্পোনেন্টের স্টাইল

প্যারেন্টের স্কোপড CSS চাইল্ড কম্পোনেন্টের ভেতরে পৌঁছায় না। চাইল্ডকে স্টাইল দেওয়ার দুটি উপায়:

### `class` প্রপ পাঠানো

```html
<Card class="highlight" />
```

কম্পোনেন্টে লেখা থাকে `class="card {{ props.class }}"`, তাই রুটে `highlight` বসে। সেই class-এর স্টাইল লিখুন কম্পোনেন্টের নিজের `<style>`-এ:

```css
.card.highlight {
    border-color: gold;
}
```

অথবা প্যারেন্টের `<style global>`-এ। প্যারেন্টের সাধারণ `<style>` এখানে কাজ করে না, কারণ সেটি শুধু প্যারেন্টের নিজের এলিমেন্টে লাগে।

### `<style global>` ব্যবহার

প্যারেন্টে `<style global>` লিখলে সেটি সব জায়গায় লাগে, চাইল্ডের ভেতরেও। নাম যেন অন্য কিছুর সাথে না মেলে, সেদিকে তখন নিজেকে খেয়াল রাখতে হয়।

## স্লটের কনটেন্ট

কম্পোনেন্ট ট্যাগের ভেতরে লেখা কনটেন্ট যে ফাইলে লেখা, সেই ফাইলের স্টাইলই পায়:

```html
<!-- pages/page.alo -->
<Card title="হ্যালো">
    <p class="note">এই p পেইজের স্টাইল পায়, Card-এর নয়।</p>
</Card>
```

## আউটপুট

- সব CSS মিলে একটি ফাইল হয়: `dist/assets/style.<hash>.css`। আগে থাকে `global/`-এর CSS, তারপর ব্যবহৃত `.alo` ফাইলগুলোর।
- যে কম্পোনেন্ট কোথাও ব্যবহার হয়নি, তার CSS আউটপুটে যায় না।
- `build`-এ CSS মিনিফাই হয়; `dev`-এ থাকে পড়ার মতো।
- CSS-এর `url(/images/bg.png)`-এ base path নিজে থেকে বসে।
