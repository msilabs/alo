## মূলনীতি

Alo-র লক্ষ্য: HTML জানা যে কেউ পাঁচ মিনিটে শিখে ফেলবে। তাই নতুন কোনো ফিচার যোগের আগে তিনটি প্রশ্ন করা হয়:

1. **HTML জানা কেউ ফাইলটি দেখে কি অনুমান করতে পারবে কী হচ্ছে?**
2. **ব্যবহারকারীকে কি এটি শিখতে হয়, নাকি নিজে থেকেই ঘটে?**
3. **ছোট সাইটের (ব্লগ, পোর্টফোলিও, কোম্পানির সাইট) কি সত্যিই এটি লাগে?**

প্রথম প্রশ্নের উত্তর "না" হলে ফিচারটি যোগ হয় না।

## কখনো আসবে না

| ফিচার | কেন নেই |
| --- | --- |
| রিঅ্যাক্টিভিটি, স্টেট, store, ভার্চুয়াল DOM | ছোট সাইটে লাগে না। দরকার হলে নিজের পছন্দের JS লাইব্রেরি যোগ করুন। |
| ক্লায়েন্ট-সাইড রাউটিং (SPA) | প্রতিটি পেইজ একটি সাধারণ HTML ফাইল। |
| `import` | সব কম্পোনেন্ট আর ডেটা আসে ফোল্ডার আর ফাইলের নাম থেকে। |
| কনফিগারেশন ফাইল, প্লাগইন | মনে রাখার কিছু নেই; দুটি ফ্ল্যাগই যথেষ্ট। |
| TypeScript | ব্রাউজারে চলে সাধারণ JS। |
| সার্ভার-সাইড রেন্ডারিং | Alo শুধু স্ট্যাটিক ফাইল বানায়। |

## ইচ্ছাকৃতভাবে বাদ

- **JS আর HTML মিনিফাই:** নিরাপদ JS মিনিফায়ারের জন্য পুরো JS পার্সার লাগে, অথচ ছোট সাইটে লাভ সামান্য। HTML-এর হোয়াইটস্পেস হুবহু রাখতে হয়।
- **reference-style Markdown লিংক, footnote, task list:** এগুলো আক্ষরিক লেখা হিসেবে আসে।
- **কোডের রং (syntax highlighting):** Markdown শুধু `class="language-js"` বসায়; হাইলাইটার নিজে বেছে নিন।

## পরে ভাবা হবে

আসল ব্যবহারকারীরা চাইলে, আর উপরের তিন প্রশ্নে উত্তীর্ণ হলে:

- পেজিনেশন
- নামযুক্ত স্লট
- একাধিক লেভেলের ডায়নামিক রাউট
- প্রপস ঘোষণা

## বদলে যা আছে

| যা নেই | বদলে |
| --- | --- |
| `:prop="expr"` | `prop="{{ expr }}"` |
| `@if`, `v-if`, `a-if` | `<template if>` |
| `<li for>` | `<template for><li>…</li></template>` |
| `{{ title }}` (কম্পোনেন্টে) | `{{ props.title }}` |
| `$props`, পেইজে লুকানো JSON | `data-*` আর `$el.dataset` |
| `[id]`, `[name]` | শুধু `[slug]` |
| কনফিগারেশনে base path | `--base` ফ্ল্যাগ |

প্রতিটি সিদ্ধান্তের কারণ লেখা আছে [DECISIONS.md](https://github.com/msilabs/alo/blob/main/DECISIONS.md)-তে।

## কখন Alo ঠিক টুল নয়

- ড্যাশবোর্ড বা লগইনওয়ালা অ্যাপ, যেখানে পেইজ ব্যবহারকারীভেদে আলাদা।
- যে সাইটের কনটেন্ট প্রতি অনুরোধে সার্ভার থেকে আসে।
- হাজার হাজার পেইজের সাইট, যেখানে পেজিনেশন আর আংশিক বিল্ড দরকার।

ব্লগ, পোর্টফোলিও, ডকুমেন্টেশন, ল্যান্ডিং পেইজ বা কোম্পানির সাইটের জন্য Alo বানানো।
